# 文档阅读指南

<div class="doc-lead">以一笔交易为主线，逐步理解架构、资产和异常处理。</div>

## 推荐学习路线

1. 阅读[公用基础](/pages/0401)，理解委托、成交、冻结等共用名词；需要时再查各域「相关」名词篇。
2. 阅读系统架构，认识用户、账户、交易与行情的边界。
3. 阅读现货的完整交易流程，用资产变化建立直观认识。
4. 学习合约的持仓与保证金，再学习期权的周期与结果判定。
5. 阅读钱包和 OTC，理解链上、链下与内部账务的区别。
6. 回到异常处理和对账，检查正常路径以外的设计。

## 每篇文档怎样读

先看业务目标，再看图中的参与者，最后检查输入、状态变化、资金变化和结束条件。流程图中的箭头表示业务先后或依赖，不保证所有步骤是同一个数据库事务。

## 贯穿示例

现货章节统一使用“买入 0.01 BTC，先成交 0.006 BTC，再撤销剩余 0.004 BTC”的例子。该案例串联下单、撮合、结算、撤单和对账，避免每一章更换假设。
