# 高频手续费缓存

<div class="doc-lead">对配置为「高频」的交易对，按用户当日已撮合卖单次数抬高卖单手续费，并设上限。</div>

类：`HfTradeFeeCache`。

## 配置态（进程级）

| 项 | 含义 |
| --- | --- |
| `hfTradeNameSet` | 参与策略的交易对名称集合 |
| `hfTradeFeeMax` | 手续费上限 |
| `hfTradeFeeIncr` | 每多一笔卖单成交递增的步长 |

由 `initRequiredParam` 在启动/配置加载时写入。

## 运行态

```text
Guava Cache：key = yyyy-MM-dd_tradeName
            value = ConcurrentHashMap<userId, Set<entrustId>>
```

- 写入过期约 2 天（`expireAfterWrite`）。
- `putUserSellDayTag`：卖单侧记录当日已撮合委托 id（单用户集合有上限，代码中约 20）。
- `getFeeAfterIncr`：仅对**卖单**、且交易对在集合内时，在原始卖费率上按集合大小 × 步长递增，不超过 `hfTradeFeeMax`；买单原样返回。
- 可从持久化回放：`loadFromPersistDb`；另有 Redis 键前缀 `hf_trade:userEntrustMap:` 用于旁路持久。

基础 VIP 费率仍来自[用户手续费缓存](/pages/070806)；本缓存只叠加高频惩罚层。
