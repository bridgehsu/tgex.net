# 交易对缓存

<div class="doc-lead">撮合侧装载的交易对与商户交易对信息，供开放接单、规则校验与初始化进度判断使用。</div>

类：`TradeCache`。

## 内部结构

| 结构 | 键 → 值 | 用途 |
| --- | --- | --- |
| `TRADE_TYPE_ID_CACHE` | `tradeId` → `TradeType` | 按总交易对 id 查 |
| `TRADE_TYPE_NAME_CACHE` | `symbol` → `TradeType` | 按交易对标识查 |
| `PARTNER_TRADE_TYPE_ID_CACHE` | 商户交易对 id → `PartnerTradeTypeInfo` | 按商户交易对主键查 |
| `PARTNER_TRADE_TYPE_TRADE_ID_CACHE` | `(tradeId, partnerId)` → `PartnerTradeTypeInfo` | 按总交易对 + 商户查 |
| `INIT_LOAD_TRADE_SET` | `symbol` 集合 | 初始化仍在加载中的交易对 |

## 存什么

- **`TradeType`**：平台级交易对定义（标识、基础/计价币、精度与开关等，以实体字段为准）。
- **`PartnerTradeTypeInfo`**：某商户对该交易对的启用、买卖开关、停盘等业务配置。

撮合初始化「加载交易对」阶段写入本缓存；运行中配置变更也会刷新对应条目。`INIT_LOAD_TRADE_SET` 用于观察还有多少交易对未装完，装完后删除。

## 阅读时抓住什么

本缓存回答「这个 symbol / 商户能不能接单、币种与精度是什么」，**不**存余额或委托。余额见[用户币币账户缓存](/pages/070802)；委托见[委托热数据缓存](/pages/070803)。初始化顺序见[撮合初始化链路](/pages/070503)。
