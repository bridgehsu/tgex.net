# 下单等待缓存

<div class="doc-lead">把「业务 id → 等待中的 Future」放在内存里，撮合链记账成功或失败后完成该 Future，从而让同步 RPC 返回。</div>

类：`BasicFutureCache`。

## 结构

```text
ConcurrentHashMap<String id, BasicFuture<MatchResponse>>
```

| 方法 | 作用 |
| --- | --- |
| `setBasicFutureMap` | 登记等待 |
| `setSuccess` / `setError` | 完成 Future（成功或带错误码） |
| `getBasicFutureMap` / `removeBasicFutureMap` | 查询 / 摘除 |

## 定位

这不是业务权威态（不含余额、委托内容），而是**同步等待通道**：委托侧调撮合下单时，常需等到「冻结并建单」阶段有结果再返回委托编号。进簿与成交可在同链继续，不必全部完成才唤醒 Future。见[下单主流程](/pages/070502)、[撮合主流程](/pages/070508)。
