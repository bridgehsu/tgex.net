# 用户手续费缓存

<div class="doc-lead">撮合侧计算委托手续费时使用的 VIP 等级与费率表；成交计价前在内存解析买/卖费率。</div>

类：`UserFeesCache`。

## 内部结构

| 结构 | 键 → 值 | 用途 |
| --- | --- | --- |
| `USER_VIP_CACHE` | `userId` → `VipLevel` | 用户当前 VIP 等级；VIP6 可带限定交易对列表 |
| `PARTNER_COIN_VIP_FEES` | `(partnerId, vipLevel)` → `Map<coinId, UserVipVO>` | 商户 × VIP 档 × 币种费率 |

`VipLevel` 内含：

| 字段 | 含义 |
| --- | --- |
| `level` | VIP 档位字符串（如 `VIP6`） |
| `vip6TradeIdList` | VIP6 仅对这些 `tradeId` 生效；否则费率查询返回空 |

## 查询口径

`getUserFeesCache(partnerId, userId, coinId, tradeId, side)`：

1. 取用户 VIP；无等级 → 无费率（走其它默认逻辑）。
2. 若为 VIP6 且当前 `tradeId` 不在白名单 → 视为不生效。
3. 用 `(partnerId, level)` 取费率表，再按 `coinId` 取 `UserVipVO`。
4. 买单取 `buyFee`，卖单取 `sellFee`。

`isUserVip6` 供账务流水等标记机器人/特殊 VIP 身份。

## 与其它缓存的边界

平台币抵扣是否开启、抵扣币种与比例在[平台币抵扣缓存](/pages/070807)；本缓存只管 VIP 费率档。高频交易对上的卖单递增见[高频手续费缓存](/pages/070811)。成交时如何用本缓存计费并写入账户暂存，见[手续费计费落地](/pages/070512)。
