# 币种计价缓存

<div class="doc-lead">按商户 × 币种缓存参考计价（注释为币种价格 / CNY 口径），供需要折算的撮合侧逻辑读取。</div>

类：`CoinCnyPriceCache`。

## 结构

```text
Table<partnerId, coinId, BigDecimal>
```

| 方法 | 作用 |
| --- | --- |
| `setCoinCnyPrice(partnerId, coinId, price)` | 单币种写入 |
| `setCoinCnyPrice(partnerId, priceMap)` | 批量写入该商户一行 |
| `getCoinCnyPrice` | 读取 |

与[最近成交价缓存](/pages/070808)不同：最近成交价按 **交易对 symbol**、服务撮合比价；本缓存按 **商户 + 币种**、服务计价折算。初始化装载见[撮合初始化链路](/pages/070505)。
