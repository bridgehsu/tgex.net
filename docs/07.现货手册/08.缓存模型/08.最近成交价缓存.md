# 最近成交价缓存

<div class="doc-lead">按交易对标识保存撮合侧最近一次成交价，供比价与价格参考使用。</div>

类：`MatchingLastPriceCache`。

## 结构

```text
ConcurrentHashMap<symbol, Long price>
```

价格为引擎内定点 `Long`（乘精度因子），与委托价字段同口径。

## 行为

- 初始化：可从行情等服务装入各对最近价。
- 运行中：成交确认后 `setMatchingLastPriceCache` 更新。
- 查询：`getMatchingLastPriceCache(symbol)`。

本缓存是撮合进程内的价格参考，不等于行情服务对外推送的完整 ticker；展示侧见[行情推送流程](/pages/070509)。同组：[交易对缓存](/pages/070804)。
