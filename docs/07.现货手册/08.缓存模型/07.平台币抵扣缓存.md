# 平台币抵扣缓存

<div class="doc-lead">哪些用户开启了平台币抵扣手续费，以及各商户的抵扣币种、最低数量与折扣比例。</div>

类：`UserDeductionFeesCache`。

## 内部结构

| 结构 | 键 → 值 | 用途 |
| --- | --- | --- |
| `USER_DEDUCTION_FEES_CACHE` | `userId` 集合 | 用户是否开启抵扣 |
| `PARTNER_DEDUCTION_FEES_CACHE` | `partnerId` → `PartnerDeductionFees` | 商户抵扣规则 |

### PartnerDeductionFees

| 字段 | 含义 |
| --- | --- |
| `partnerId` | 商户 |
| `coinId` | 抵扣用平台币币种 |
| `minCount` | 抵扣相关最低数量门槛 |
| `deductionRadio` | 折扣比例（装入时按规则换算） |

## 怎么用

- 成交前判断用户是否在集合中、商户是否配置了抵扣模型。
- 真正扣可用仍发生在[用户币币账户缓存](/pages/070802)（抵扣币种的 `total` 减少，并累加 `paTotal` / `adTotal`）。
- VIP 基础费率仍来自[用户手续费缓存](/pages/070806)。

初始化时从账务 / 商户配置装入，见[撮合初始化链路](/pages/070505)。
