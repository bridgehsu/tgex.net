# 商户分成比例缓存

<div class="doc-lead">按商户 id 缓存手续费分成比例；成交计费时拆平台与商户份额用。</div>

类：`PartnerExtractRateCache`。

## 结构

```text
ConcurrentHashMap<partnerId, BigDecimal extractRate>
```

| 行为 | 说明 |
| --- | --- |
| `setPartnerExtractRateCache` | 写入或更新比例 |
| `getPartnerExtraRateCache` | 读取；无配置时返回 `0` |

本缓存只存「分成比例」标量。用户/币种 VIP 费率在[用户手续费缓存](/pages/070806)；平台币抵扣规则在[平台币抵扣缓存](/pages/070807)；实际扣减与 `paTotal` / `adTotal` 暂存在[用户币币账户缓存](/pages/070802)。
