# 用户状态缓存

<div class="doc-lead">撮合进程内按用户 id 缓存「是否允许交易」；缺省视为可交易。</div>

类：`UserStatusCache`。

## 结构

```text
ConcurrentHashMap<userId, Boolean>
```

| 取值 | 含义 |
| --- | --- |
| `true` | 可交易 |
| `false` | 禁止交易 |
| 无条目 | 视为可交易（`userStatus` 返回 `true`） |

## 行为

- `setUserStatus`：用户 / 风控等事件写入禁交或恢复。
- `userStatus`：下单等路径快速判断；未命中不挡单。
- `removeUserStatus`：清除该用户条目。

本缓存只存开关，不含余额、VIP 或委托。费率见[用户手续费缓存](/pages/070806)；资金见[用户币币账户缓存](/pages/070802)。
