# OTC相关

<div class="doc-lead">OTC 把数字资产托管与线下法币支付拼成一笔交易。</div>

本篇是名词速查。完整流程见[OTC 手册](/pages/1101)。

## 参与者与挂单

| 名词 | 含义 |
| --- | --- |
| 商家 | 提供买卖报价与收款方式的一方 |
| 广告 / 广告委托 | 商家发布的可成交条件与额度 |
| 法币 | 线下支付使用的货币 |
| 支付方式 | 银行转账、第三方支付等约定渠道 |
| 单笔限额 / 时限 | 订单金额范围与付款、放币时限 |

## 订单过程

| 名词 | 含义 |
| --- | --- |
| 下单 | 用户按广告条件创建 OTC 订单 |
| 托管 | 商家侧数字资产被占用，等待交易完成 |
| 标记已付款 | 买方声明已完成线下支付 |
| 收款确认 | 商家确认收到法币 |
| 放币 | 托管资产释放给买方 |
| 取消 / 超时 | 未在时限内完成时的结束方式 |
| 申诉 | 双方争议时进入人工或规则处理 |

状态与异常见[OTC 手册 · 核心交易流程](/pages/1103)与[风控与异常处理](/pages/1104)。
