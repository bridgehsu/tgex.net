# 其他相关

<div class="doc-lead">支撑交易闭环的周边名词，按域速查。</div>

本篇不展开流程。细节见对应用户、商户、运营、量化、报表章节。

## 用户与权限

| 名词 | 含义 |
| --- | --- |
| 用户 / 身份认证 | 注册登录后的主体与核验 |
| 会话 | 登录后的访问凭证与有效期 |
| 安全验证 | 敏感操作的二次校验 |
| 业务权限 / 后台角色 | 可执行操作与菜单数据范围 |
| 邀请关系 / 用户关系 | 邀请、代理等关系链 |

见[用户与账户](/pages/0501)。

## 商户与后台

| 名词 | 含义 |
| --- | --- |
| 商户 | 租户或运营主体，常带独立配置与数据范围 |
| 总后台 / 商户后台 | 平台级与商户级管理入口 |
| 应用配置 / 产品管理 | 交易产品、费用、开关等配置 |
| 审核 / 资金调整 | 提现、调账等需审批的操作 |
| 审计记录 | 关键操作留痕 |

见[商户与后台管理](/pages/1401)。

## 运营与量化

| 名词 | 含义 |
| --- | --- |
| 活动 / 参与资格 | 运营活动及其准入条件 |
| 邀请奖励 / 手续费返还 | 按关系或交易产生的奖励 |
| 策略 / 跟单 / 信号 | 量化或跟单的决策与触发 |
| 机器人账户 | 用于做市或策略的专用账户 |
| 外部平台 | 对接的第三方行情或交易通道 |

见[运营与奖励](/pages/1301)、[机器人与量化](/pages/1201)。

## 风控与报表

| 名词 | 含义 |
| --- | --- |
| 风控规则 / 风险事件 | 触发限制的条件与一次具体事件 |
| 限制交易 / 冻结提现 | 常见处置动作 |
| 统计口径 | 报表如何定义成交量、入金等指标 |
| 对账差异 | 账户、订单或链上核对不一致的结果 |

见[报表与风控](/pages/1501)。
