# 现货相关

<div class="doc-lead">现货的核心是基础币与计价币的交换。</div>

本篇是名词速查。完整流程见[现货手册](/pages/0701)。共用的委托 / 撮合 / 成交见[公用基础](/pages/0401)。

## 交易方向与订单

| 名词 | 含义 |
| --- | --- |
| 买入 / 卖出 | 用计价币换基础币，或用基础币换计价币 |
| 限价单 | 指定价格或更优价格才成交 |
| 市价单 | 按对手盘可成交价格尽快成交 |
| 优价成交 | 实际成交价不劣于委托条件 |

## 资金与费用

| 名词 | 含义 |
| --- | --- |
| 资金占用 / 预占 | 下单后冻结对应可用余额，防止重复使用 |
| 计价币占用 | 买单通常冻结计价币 |
| 基础币占用 | 卖单通常冻结基础币 |
| 手续费 | 成交时按规则收取；常区分 taker / maker |
| 成交结算 | 成交后双方币种余额按成交结果入账，并处理占用释放 |

## 规则边界

| 名词 | 含义 |
| --- | --- |
| 精度 | 价格、数量允许的小数位 |
| 最小数量 / 最小金额 | 下单门槛 |
| 交易状态 | 交易对是否可交易、是否仅撤单等 |

细节与异常路径见[现货手册 · 交易规则](/pages/0703)与[核心交易流程 · 业务流程](/pages/070501)。
