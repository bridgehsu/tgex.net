# 钱包账务

<div class="doc-lead">分清链上对象与内部记账，再理解充提如何把两者连起来。</div>

本篇是名词速查。内部账户基础见[公用基础](/pages/0401)；流程见[钱包手册](/pages/1001)与[资产与账务](/pages/0601)。

## 链上对象

| 名词 | 含义 |
| --- | --- |
| 钱包地址 | 链上收款 / 出款地址 |
| Memo / Tag | 部分网络用于区分入账归属的附加标识 |
| 代币合约 | 代币在某网络上的合约标识 |
| 确认数 | 链上交易达到可信所需的区块确认数量 |
| 交易哈希 | 链上交易的唯一标识 |
| 网络费用 | 链上转账支付的矿工费 / gas 等 |

## 充提与归集

| 名词 | 含义 |
| --- | --- |
| 充值 | 链上转入后，确认达标再记入内部账户 |
| 提现 | 内部账户扣减（常先冻结）后，审核并广播链上转出 |
| 归集 | 将分散地址资金集中到指定钱包的运营动作 |
| 待确认充值 | 已发现链上转入、尚未达到入账条件的记录 |
| 审核 / 签名 / 广播 | 提现链路中的人工或系统关键步骤 |

## 内部账务衔接

| 名词 | 含义 |
| --- | --- |
| 入账 | 充值确认后增加内部可用（或按规则入对应账户） |
| 冻结 / 解冻 / 释放 | 提现或业务占用时的余额状态变化 |
| 划转 | 用户不同业务账户之间的资金移动 |
| 链上对账 / 补扫 | 核对链上记录与内部流水，并处理漏扫或重组 |

不要把“有链上余额”直接等同于“内部可用余额”。二者只通过充提等流程关联。
