# 期权相关

<div class="doc-lead">先确认本工程产品规则，再套用任何“期权”计算模型。</div>

本篇是名词速查。完整流程见[期权手册](/pages/0901)。

## 产品与周期

| 名词 | 含义 |
| --- | --- |
| 期权产品 | 本工程中按规则交易的周期型产品（实现上可能有多个版本） |
| 周期 | 一笔订单从参与到结果判定的时间窗口 |
| 购买窗口 | 允许下单的时间范围 |
| 看涨 / 看跌 / 看平 | 方向选择；具体判定以产品规则为准 |
| 触碰 | 价格在周期内触及某条件时的结果规则（若产品启用） |

## 价格、订单与结算

| 名词 | 含义 |
| --- | --- |
| 参考价格 / 结算价 | 用于判定结果或结算的价格依据 |
| 期间高低价 | 周期内行情极值，部分规则会用到 |
| 扣款 | 下单或参与时按规则扣减资金 |
| 到期 | 周期结束并进入结果判定 |
| 收益结算 / 退还 / 退单 | 按结果入账、退回或取消未完成订单 |

## 用语边界

工程中已观察到涨、跌、平、周期和触碰相关实现。不能直接把传统标准期权的权利金、行权价和 Greeks 套到这些产品上。

学习顺序：先读[期权手册 · 产品与交易规则](/pages/0902)，再看设计和流程章节。
