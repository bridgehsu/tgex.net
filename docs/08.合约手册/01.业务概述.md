# 业务概述

合约交易不是「用一种币换成另一种币到手」，而是用保证金撬动更大的名义敞口：你表达看涨或看跌，成交后形成**持仓**；价格波动带来浮盈浮亏，保证金不够时可能被**强平**。现货关心币有没有换成；合约还要盯仓位够不够、保证金还撑不撑得住。

下面先把核心概念分开，再跟一笔统一数字的开多 → 部分平仓，后文规则、设计与流程沿用同一组数。

## 合约是什么 {#basics}

说白了：你先准备一笔保证金（常见是 USDT），再决定做多还是做空。杠杆让同样保证金能对应更大名义价值；赚亏主要体现在持仓的盈亏上，而不是立刻「拿到一堆 BTC 放进现货钱包」。

在常见的 **BTCUSDT 线性永续**（以 USDT 结算）里：

- **开多**：看涨；价格涨，多仓浮盈倾向增加  
- **开空**：看跌；价格跌，空仓浮盈倾向增加  
- **平仓**：关掉已有敞口的一部分或全部，浮盈浮亏落成已实现  
- **强平**：权益撑不住维持要求时，系统强制减仓或平仓  

和现货、期权的差别：

| 产品 | 更关心什么 |
| --- | --- |
| 现货 | 单有没有、成交了没有、币归谁 |
| **合约** | 持了多少仓、保证金够不够、会不会被强平 |
| 期权 | 约定权利、到期与行权结果 |

读合约时先把下面四样分开，别混在一块：

| 看什么 | 人话 |
| --- | --- |
| 委托（订单） | 我还想开 / 平多少？这单现在什么状态？ |
| 持仓 | 我现在敞口多大？方向？开仓均价？还能平多少？ |
| 保证金 / 账户 | 合约账户里可用多少？被仓位占用多少？ |
| 盈亏 | 浮盈浮亏多少？平仓后实现了多少？ |

打开合约交易页，通常还会看到：

| 页面上 | 你在看什么 |
| --- | --- |
| 合约产品 | 如 BTCUSDT 永续；结算币、合约类型 |
| 杠杆 / 保证金模式 | 几倍杠杆；逐仓还是全仓 |
| 盘口 / 标记价 | 盘口是挂单意愿；标记价常用于浮盈与风控 |
| 当前委托 | **你的**未完结开平仓单 |
| 持仓 | **你的**有效敞口 |
| 合约账户余额 | 可用、占用、权益相关展示 |

记住两个容易混的点：

1. **买卖**和**开平**不是同一维度：买入可以开多，也可以平空。  
2. **最新成交价**、**指数价**、**标记价**用途不同；强平与浮盈通常看标记 / 风险参考价，不是随口拿盘口一档。

## 一笔交易案例 {#complete}

后文合约章节尽量沿用同一组数：

> 线性永续 **BTCUSDT**，**10 倍**杠杆，**开多 0.01 BTC**，成交价按 **60,000 USDT**；随后 **平掉 0.006 BTC**，剩余 **0.004 BTC** 仍持仓。先忽略手续费与资金费。

名义价值约 `0.01 × 60,000 = 600 USDT`。简单估算初始保证金约 `600 / 10 = 60 USDT`（真实产品还有手续费缓冲、档位风险限额等，以规则为准）。

假设合约账户里原先有 **1,000 USDT** 可用：

| 阶段 | 可用约 | 保证金占用约 | 持仓 | 委托 | 页面上大致怎样 |
| --- | ---: | ---: | --- | --- | --- |
| 初始 | 1,000 | 0 | 无 | 无 | 合约账户能用 1,000 |
| 开多成交 0.01 | 940 | 60 | 多 0.01 @ 60,000 | 完结或无剩余 | **持仓**出现多仓；占用增加 |
| 平仓成交 0.006 | 占用随减仓释放 | 随规则重算 | 多 0.004 | 平仓单完结 | 已实现盈亏按平仓段结算；持仓变小 |

读表时的口诀：

1. **委托**：开仓 / 平仓单有没有、成了多少  
2. **持仓**：敞口从 0.01 减到 0.004，开仓均价口径按产品规则  
3. **保证金**：开仓占用 → 平仓后部分释放；不是现货那种「冻计价币买货」  
4. **盈亏**：未平时看浮盈（常挂标记价）；平掉的一截变成已实现  

若标记价持续向不利方向走、权益低于维持要求，就不再走「你主动平仓」，而走[强平与清算](/pages/080503)。系统内开仓怎么受理，见[开仓主流程](/pages/080501)；平仓见[平仓主流程](/pages/080502)。

### 开空对称理解

同一组名义：开空 0.01 BTC @ 60,000，占用同样量级保证金（模式与费率另计）。价格下跌利多空仓浮盈；平空减少空头敞口。开多 / 开空是方向相反的持仓，不是现货的买卖成交对手关系本身。

### 手续费、资金费与强平

| 扩展 | 教学处理 |
| --- | --- |
| 开平手续费 | 占用与到账会略少于「裸名义 / 杠杆」估算 |
| 资金费 | 按产品周期在多空间结算；**不等于**借币利息；未启用则不要写进主路径 |
| 强平 | 由标记价等风险口径触发；与用户主动平仓分流，见[强平与清算](/pages/080503) |
