# 交易规则

<div class="doc-lead">先确定订单是否合法，再占用保证金或可平数量。合法规则是委托校验的输入；对象建模见[核心设计](/pages/0804)；谁执行见[系统架构](/pages/0802)。</div>

规则检查发生在真正改热钱包 / 持仓之前。不合法应拒单，而不是带着错误参数进入可成交状态。平台开仓校验落点见[开仓主流程](/pages/080501)。

## 开平仓与方向 {#direction}

买卖方向与开平仓用途不是同一个维度：

| 维度 | 例子 |
| --- | --- |
| 交易方向 | 买 / 卖（挂到订单簿的一侧） |
| 开平用途 | 开多、开空、平多、平空 |

买入可以开多，也可以用于平空。平仓量必须落在**可平数量**内，防止多笔平仓单重复使用同一持仓。

**本册流程覆盖**：平台永续 · 限价开仓 / 平仓。市价、止盈止损、计划委托等能力以产品启用为准，逐步时序未全部单开。

## 杠杆与保证金模式 {#margin}

| 概念 | 含义 |
| --- | --- |
| 杠杆 | 放大名义敞口的倍数；不改变「价格涨跌 1%」对同等名义的绝对波动，但改变保证金需求 |
| 逐仓 | 保证金与风险按仓位隔离（实现细节按产品） |
| 全仓 | 同一结算币权益共享风险（实现细节按产品） |

教学示例（与[业务概述 · 案例](/pages/0801#complete)同一组数）：名义 600 USDT、杠杆 10 倍时，简单初始保证金约 60 USDT，**尚未**计手续费、资金费与风险限额档位。实际占用以撮合受理结果为准。

开仓前至少要能回答：

1. 产品是否可交易、涨跌幅是否允许？  
2. 杠杆是否超过该产品 / 用户档位上限？  
3. 可用保证金是否覆盖初始占用（含规则要求的费用缓冲）？  
4. 若为平仓：可平数量是否足够？

## 价格、限额与费用 {#fees}

| 价格 | 常见用途 |
| --- | --- |
| 最新成交价 | 盘口成交事实、部分展示 |
| 指数价 | 由外部现货等组成的参考 |
| 标记价 | 浮盈展示与强平扫描等风险口径（以产品为准） |

用于盈亏展示、强平和成交的价格依据必须分开写清，不能「一个最新价打天下」。

手续费需要说明：费率来源、收取币种、收取时机（通常成交时）、舍入。  
资金费：仅当产品启用；是多空之间按规则的定期结算，**不能**等同借币利息，也不能默认所有合约都收。

风险限额 / 仓位档位会提高维持要求或限制开仓规模；写规则时要能指向「档位从哪来」，避免只写「杠杆越高越危险」这种空话。
