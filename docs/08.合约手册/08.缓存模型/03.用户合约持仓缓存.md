# 用户合约持仓缓存

<div class="doc-lead">未关闭敞口的热数据：方向、数量、均价、可平、仓位保证金等。订单簿管挂单排队；本缓存管「你已经持了什么仓」。</div>

类：`UserContractPositionCache`。持仓键通常组合合约产品、仓位类型、开仓方向等（工程字段以 `contractAllType` 一类组合为准）。

## 职责

| 动作 | 对持仓的影响（语义） |
| --- | --- |
| 开仓成交 | 新建或加仓；更新均价与可平 |
| 平仓成交 | 减仓；可平减少；足够时移除持仓 |
| 强平 | 减仓或清空；可能伴随状态锁定 |
| 加 / 减保证金 | 改仓位保证金字段，不改成交均价本身 |

比价与成交时通过持仓 / 委托 id 回查，与[用户合约账户缓存](/pages/080802)一起改完才算一笔事件成功。

## 边界

- 撤销未成交开仓单：**不**通过本缓存减少已有持仓。  
- 盘口深度展示不等于本缓存汇总。  
- 强平锁定态另见用户状态缓存（总览简述）。
