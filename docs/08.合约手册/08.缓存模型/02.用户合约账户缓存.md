# 用户合约账户缓存

<div class="doc-lead">合约侧「还能不能开仓、占用了多少保证金」的权威内存表；对应现货的用户币币账户缓存，但服务的是合约权益，不是现货买卖冻结。</div>

类：`UserContractAccountCache`（工程注释亦称用户合约账户缓存）。键一般按用户 × 结算币种等定位合约钱包格子。

## 职责

| 动作 | 对格子的影响（语义） |
| --- | --- |
| 划转入金 | 增加可用 |
| 开仓占用 | 可用减少、占用增加（按保证金规则） |
| 平仓 / 强平释放与结算 | 占用与可用按盈亏结果重算 |
| 加 / 减保证金 | 在维持要求允许范围内调整占用与可用 |

运行中以本缓存为准；Redis / MySQL 承接快照与流水。见[保证金与资金协同](/pages/080505)。

## 边界

- **不是**现货 `UserBBAccountCache`：现货买卖冻结不直接改本表。  
- **不替代**持仓缓存：仓位数量与可平在[用户合约持仓缓存](/pages/080803)。  
- 外部资金变动应走撮合改账通道，与开平仓串行，避免交叉写花。
