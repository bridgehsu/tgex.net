# 行情推送流程

<div class="doc-lead">撮合产出深度 / 成交事件，行情加工后推盘口与成交；行情还维护指数 / 标记价并回喂撮合做风控。推送只服务展示与价格源，不裁定持仓对错。</div>

## 1. 业务事件进入行情

| 来源 | 内容 |
| --- | --- |
| 撮合 → MQ | 深度、成交等 |
| 外部指数成分 / 配置 | 指数计算输入 |
| 订阅连接 | 客户端经网关 / WS 订阅 |

## 2. 加工与推送

行情侧按类型更新缓存并标记可推：盘口聚合、最新成交、K 线、指数与标记等。再按订阅分发给客户端。

| 展示 | 含义 | 别当成 |
| --- | --- | --- |
| 盘口 | 未成交挂单聚合 | 你的持仓 |
| 最新成交 | 已确认成交事实 | 标记价 |
| 标记价 | 风控 / 浮盈常用参考 | 你的成交均价 |

## 3. 标记价回喂撮合

标记（及指数）更新会发给撮合，供浮盈计算与[强平扫描](/pages/080503)。这是异步旁路：用户开平仓回包不依赖「这一跳标记价已经推到所有人」。

## 4. 异常与断线

| 情况 | 策略方向 |
| --- | --- |
| 价格源中断 / 异常跳变 | 暂停、降级或人工规则；不拿过期价冒充实时标记价 |
| 客户端断线 | 先拉快照再接增量 |
| 推送延迟 | 不以推送快慢否定撮合内已成交事实 |

未确认事实前，不应随意补历史价、改历史成交或直接改用户盈亏。
