# 平仓主流程

<div class="doc-lead">用户主动平仓：网关 → 合约委托 → 合约撮合；按可平数量占用平仓意图，成交后减少持仓、确认已实现盈亏并释放相应保证金。未成交前，原仓位风险仍在。</div>

本文以 **平多 / 平空 · 限价 · 单笔** 为主。系统强平见[强平与清算](/pages/080503)。案例数字见[业务概述](/pages/0801#complete)。

## 1. 用户 / 机器人 → 应用网关

提交平仓：合约产品、平多或平空、价格、数量（不超过可平）、来源等。

## 2. 委托：校验

失败则拒单、不调撮合：

1. 入参与产品状态  
2. 对应方向持仓是否存在  
3. 平仓数量 ≤ 可平数量（扣除已挂出的平仓占用）  
4. 涨跌幅、精度等产品规则  

## 3. 委托 → 撮合：平仓

撮合在事件链上：

1. 占用可平数量，建立平仓委托并进簿  
2. 成交则减少持仓、结算该段已实现盈亏、按规则释放保证金  
3. 剩余平仓量挂簿或结束；持仓可平与占用同步更新  

平仓与开仓、强平争同一持仓时，以撮合串行结果为准，不能按客户端点击瞬间的旧可平快照重复平。

## 4. 同步返回与异步推送

成功回包表示平仓委托已受理。盘口与成交展示走[行情推送流程](/pages/080504)。超时先查委托与持仓，勿重复盲目平仓。
